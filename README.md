# Arc Agent Command Center

An autonomous AI Agent system built for the **Arc Network**. This system features an automated smart contract orchestrator and a premium glassmorphic dashboard for real-time mission control.

## 🚀 Features

- **Autonomous Agent**: A Python-based orchestrator that monitors balances and pushes missions to the Arc blockchain.
- **Neural Dashboard**: A premium UI for visualizing agent state and deploying new missions manually via MetaMask.
- **Zero-Code Automation**: One-click setup script (`Run_Me.py`) to install dependencies and launch the system.
- **Created by Zero**: Built for the future of on-chain finance.

## 🛠️ Tech Stack

- **Smart Contracts**: Solidity (0.8.20)
- **Agent Logic**: Python (Web3.py, Solcx)
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism), Ethers.js
- **Network**: Arc Testnet (Chain ID: 5042002)

## 📦 Getting Started

1.  **Clone the Repo**:
    ```bash
    git clone <your-repo-url>
    cd arc_agent_system
    ```
2.  **Run the Automation**:
    ```bash
    python Run_Me.py
    ```
3.  **Open the Dashboard**:
    Navigate to `http://localhost:8000/dashboard.html` in your browser.

## 🔑 Configuration

Fill in your `.env` file with your **Private Key** and **Arc RPC URL** to enable autonomous deployments.
